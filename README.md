# IRONVAULT FITNESS — Website Demo

A responsive, single-page gym equipment business website concept.

## Run locally
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in a modern browser.
3. Internet access is needed for Google Fonts and the remote Unsplash product/hero images.

## Included
- Responsive navigation and mobile menu
- Product catalogue with category filters
- Interactive demo cart and quantity controls
- Services, about, testimonials and contact sections
- Enquiry form front-end interaction

## Before using for a real business
- Replace the fictional brand, logo, prices, product descriptions and images.
- Replace demo phone/email details.
- Replace example testimonials with verified customer reviews.
- Connect the enquiry form to a backend, email service or CRM.
- Connect cart/checkout to inventory, shipping, tax and a payment gateway.
- Add privacy policy, terms, return policy and shipping information.
- Review product claims, warranty terms and delivery promises before publishing.

This is a front-end demo. It does not process payments or transmit form submissions.
